**Button** — the universal Ananta Ions CTA; use for every primary and secondary action.

```jsx
<Button variant="primary">Get started</Button>
<Button variant="outline">Read the documentation</Button>
<Button variant="ghost">Learn more</Button>
```

Variants: `primary` (gold fill, the default CTA), `outline` (gold border on light canvas — the secondary), `outline-on-dark` (white border for dark hero/footer strips), `ghost` (inline arrow link, auto-appends "→"), `disabled` (flat gray). Sizes `lg` / `md` / `sm`. Keep only one gold-fill button per fold; neutralize others to `outline`.
