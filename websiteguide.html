ANANTA IONS — Website Guide

How the ANANTA IONS marketing website is structured, how to maintain it, and how to replace the placeholder content with real details. The site is a multi-page static build — no framework build step, no server — designed to be easy to edit and extend.

Content status. The site currently ships with placeholder content — project names, specifications and pricing are illustrative and must be replaced before launch. Every placeholder is marked in the UI and lives in one file (data.jsx), so swapping in real details is a single-file edit.

1 · What the site is

A dark, engineering-grade marketing site for ANANTA IONS — a technology company that engineers firmware, embedded systems, connectivity and intelligent electronics, from silicon to production-ready products. The site is built on the bound Ananta Ions Design System (gold #d4af37 accent, the corner-square motif, 2px angular geometry, Inter type), extended onto deep-black surfaces with a copper accent reserved for technical diagrams.

It supports three primary visitor journeys:

  1. Browse ready-made projects — reference designs filterable by application, each leading to a project request.
  2. Explore engineering services — firmware, connectivity and embedded intelligence.
  3. Start a custom project — a four-step engineering intake form.

3 · File structure

The site is deliberately split into small, single-responsibility files so content and layout are easy to find and change.

FileWhat lives here
*.html (5)One thin page each. Loads shared scripts, then mounts that page's sections. This is where you set a page's section order.
data.jsxAll content. Projects, capabilities, firmware/connectivity/intelligence lists, industries, process steps, navigation links. Edit this to add real details.
site.cssShared styling: colour variables, layout helpers (.ai-container, .ai-section), animations, responsive rules.
primitives.jsxSmall shared building blocks: brand mark/wordmark, cards, buttons helpers, scroll-reveal wrapper.
home-sections.jsxNav, hero, engineering stack, capabilities, projects grid.
home-sections2.jsxCustom-engineering CTA, firmware, connectivity, intelligence, industries, process, why, final CTA, footer.
start-project.jsxThe four-step intake form (also usable as a modal).
assets/logo.pngThe ANANTA IONS logo (open copper ring with the ivory ion).
_ds/…The bound Ananta Ions Design System (tokens, components). Do not edit.

4 · Editing content — common tasks

Add or edit a project

Open data.jsx and edit the PROJECTS array. Each entry is an object:

{ name, cat, status, mcu, conn, desc, tags, price } — where cat must match one of the PROJECT_FILTERS values, status is 'Available' or 'Prototype', mcu is the platform, and conn is the connectivity. Add a new object to the array and it appears in the grid and filters automatically.

To add a new category, add its label to the PROJECT_FILTERS array in the same file.

Edit services, capabilities, industries or process

Each is a plainly-named list in data.jsx: CAPABILITIES, FIRMWARE, CONNECTIVITY, INTELLIGENCE, INDUSTRIES, PROCESS, WHY. Edit the text in place; the pages re-render from these lists.

Change navigation

Edit NAV_PAGES in data.jsx — an array of { label, href }. The footer link columns live in the SiteFooter component in home-sections2.jsx.

Reorder or remove a section on a page

Open that page's .html file and edit the small block near the bottom that lists the sections (e.g. <Hero/>, <Capabilities/>). Add, remove or reorder those lines.

5 · The intake form

The Start-a-Project form (start-project.jsx) collects an engineering requirement across four steps: Discover (contact & idea), Define (hardware & connectivity), Engineer (firmware & intelligence) and Deliver (production & delivery). Required fields are validated before advancing.

Not yet connected. The form is a working demo — on submit it shows a confirmation but does not send anywhere. Before launch, wire the submit handler (the next() function's final branch) to an email service, CRM, or form endpoint.

6 · Design system & brand

Colour

  • Accent: Primary Gold #d4af37 — one accent, used for CTAs and active states.
  • Surfaces: deep black #050505 through panel greys.
  • Copper #c66a25 — reserved for technical diagram traces and eyebrows.

Type & shape

  • One family: Inter (weights 400/700).
  • 2px radius everywhere — angular, never pill-shaped.
  • The gold corner square marks cards.

All tokens come from the bound design system in _ds/. When choosing new colours, use the CSS variables in site.css rather than inventing values.

Logo

The supplied mark — an open copper ring with an ivory ion in the gap — lives at assets/logo.png and is used in the nav and footer. To update it, replace that file (keep it roughly square with a transparent or black background).

7 · Running & publishing

  • Local: the site is static HTML — open index.html or serve the folder with any static server.
  • Hosting: upload the whole folder (including _ds/ and assets/) to any static host.
  • Production note: pages use an in-browser transformer for convenience. For production, precompile the .jsx files to plain JS to remove the load-time transform and the console warning.

8 · Pre-launch checklist

  • Replace all placeholder projects, specs and pricing in data.jsx.
  • Connect the intake form submit to a real endpoint.
  • Add real contact details and social links (footer, in home-sections2.jsx).
  • Confirm the logo and any real product imagery.
  • Add real page metadata / Open Graph tags per page if needed.
